# Product Messaging (English)

## 1) Technical / Clear

**Wireless Splitgrade Controller for the Darkroom**

This controller is built for practical splitgrade printing: fast, repeatable control of hard/soft exposure with a wireless workflow at the enlarger.  
Its core purpose is controlling the enlarger head remotely (ESP-NOW; confirmed working on a real LED panel head, and simulated with a second SenseCAP D1 for bench testing).

The sensor workflow is intentionally supportive, not prescriptive: it helps you reach a solid first print quickly, then hands full control back to the printer for artistic decisions.
